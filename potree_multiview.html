Streams the full 144M-point Potree octree with true level-of-detail, and overlays the real COLMAP source-photo cameras as an exploded multi-view. The overlay is camera-synced to Potree each frame.

Defaults to the public GCS bundle. The Potree engine is vendored locally at libs/potree2, so cat-web-lite runs standalone. Override any path with ?potreeBase=URL&cloud=URL&cameras=URL&images=URL&thumbs=URL&metadata=URL (e.g. point back at the local bundle_v2/ folder for offline dev).
